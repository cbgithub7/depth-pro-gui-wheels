Windows wheels of texture_baker and uv_unwrapper for Stable Fast 3D and SPAR3D, built by the `build` workflow from upstream's source at the pinned commits. Each was installed and tested before it was kept.

- `manifest.json` lists every wheel with its sha256, its upstream commit and the torch it was built against. Install a wheel only with that exact torch.
